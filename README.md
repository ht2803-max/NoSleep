**NoSleep, A Display Sleep Preventer**

Installation Instructions
-------------------------

Download the NoSleep.zip file and open up the NoSleep.app file. Thats it!

**Features**
--------

* Indefinite NoSleep - Have your screen never turn off until you turn off NoSleep
* Hours NoSleep - Have your screen never turn off for a selected amount of hours (1-24)
* Minutes NoSleep - Have your screen never turn off for a selected amount of minutes (1-60)

**Tools Used**
----------

*RUMPS (https://github.com/jaredks/rumps) - Simple creating of a menu app on MacOS

*Caffeinate - To prevent screen sleeping
